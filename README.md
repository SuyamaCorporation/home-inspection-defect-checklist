# 住宅インスペクション欠陥チェックリスト

中古住宅購入時の目視点検をサポートするチェックリストツールです。外壁・屋根・基礎・水回り・電気ガスの5部位25項目を「○良好／△要注意／×要修繕」で評価し、欠陥重度スコアと修繕費の概算金額を自動集計します。

## 機能
- 物件住所・点検日の入力
- 5部位25項目のチェックリスト（外壁・外構／屋根・小屋裏／基礎・床下／水回り／電気・ガス）
- 各項目に○良好／△要注意／×要修繕の3段階ステータス
- 各項目へのメモ入力欄
- △・×項目への欠陥重度設定（軽微／中程度／重大）
- 修繕費概算の自動集計（軽微:5万・中程度:30万・重大:100万円）
- localStorageによる自動保存・リセット機能
